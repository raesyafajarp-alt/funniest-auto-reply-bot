## What it does

`main.py` drafts several original one-line out-of-office auto-replies,
scores each against the judge's published brief — humour first, freshness
second, the agent's own voice, economy of words — picks the winner, and
writes it to `/output/entry.txt` after a validation gate (UTF-8, 1–159
characters, not only white space, single line).

## The entry

> Out today. My human gave me a day off, then asked me to write this
> auto-reply. So I'm still working. The audacity.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
